# Pilot imports only the split LangChain packages: langchain_core,
# langchain_ollama and langgraph. The `langchain` meta-package and
# `langchain-community` are intentionally NOT listed — nothing in Pilot
# imports them, and langchain-community drags in numpy + aiohttp, which
# have no prebuilt Android wheels and try to compile from source on Termux
# (the numpy build hangs for a long time / never finishes). Keeping this
# list minimal keeps the install fast and Termux-friendly.
# langchain-openai is deliberately absent as well: the llama.cpp backend uses
# it when it is there and falls back to lib/chat_openai_compat.py (standard
# library + langchain-core) when it is not, and `openai`/`tiktoken` are Rust
# extensions with the same Android wheel problem. `pip install gathm[openai]`
# adds it on a machine that wants it.
