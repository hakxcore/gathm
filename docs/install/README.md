# Installation Guides

Use the single cross-platform installer:

- `install.sh` for auto-detected setup across Linux, macOS, Termux, WSL, and Git Bash/MSYS2

## Guides

- [Termux Installation](./termux.md)

## Quick Commands

### Auto-detect (recommended if unsure)

```bash
bash install.sh
```

## Legacy Installers

`setup.sh`, `setup-termux.sh`, `./install`, and `./installation` are compatibility wrappers and now redirect to `install.sh`.
